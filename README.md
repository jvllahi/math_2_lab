# Maths II Lab Repository

This repository contains the coursework and supporting material for the Maths II lab assignments.

## Project layout

- `lab1/`: Lab Assignment 1 (source code, tests, datasets, and handout)

## What this repository includes

- One folder per assignment/lab.
- Assignment-specific source code, tests, datasets, and documentation.
- Shared repository-level files (for example, version control configuration).

## What will be added

- New assignment folders as the course progresses.
- Assignment-specific instructions inside each assignment folder.
